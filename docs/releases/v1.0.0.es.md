## Resumen

Primera versión estable de Rhapsod para TeamSpeak 3, con enlaces de YouTube, SoundCloud y Spotify.

## Cambios

- Búsqueda musical por texto con coincidencias aproximadas y clasificación según el proveedor.
- Metadatos de Spotify vinculados a audio de YouTube; Spotify no proporciona la reproducción.
- Limpieza de procesos FFmpeg después de saltar pistas y recuperación del búfer de audio.
- Instrucciones de despliegue con systemd y descripción configurable del cliente TeamSpeak.

## Actualización

Esta es la versión inicial. Para reproducir una instalación histórica, usar el código y las instrucciones de `v1.0.0`. Para una instalación nueva, usar la versión más reciente.

## Verificación

Conectar a TeamSpeak, solicitar una pista de YouTube con `!play` y probar `!skip`. Confirmar que el proceso FFmpeg anterior termina y comienza la siguiente pista.
