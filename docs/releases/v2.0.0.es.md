## Resumen

Perfil de producción para servidores de 4 vCPU y 3 GB de RAM, con extracción adaptable a la CPU disponible.

## Cambios

- Ampliación de reproducción y listas entre YouTube, SoundCloud y proveedores de metadatos.
- Mayor preparación anticipada y duración de caché de búsqueda para colas grandes.
- Información de estado del audio, registros estructurados y comprobaciones de autenticación.
- Ajustes de concurrencia y clasificación de búsquedas para servidores de mayor capacidad.

## Actualización

Respaldar configuración y datos. Revisar límites de memoria y `RHAPSOD_MAX_CONCURRENT_YTDLP_JOBS`; el perfil mayor admite 4 procesos. Spotify sigue proporcionando solo metadatos. Versiones posteriores reemplazan las rutas de resolución de YouTube usadas aquí.

## Verificación

Reproducir una cola con varios proveedores y revisar `!stats` y los registros de sesión para detectar falta de audio, recargas del búfer y uso de memoria de procesos hijos.
