## Summary

Production profile for larger hosts, targeting 4 vCPUs and 3 GB RAM while retaining CPU-adaptive extraction.

## Changes

- Expanded multi-source playback and playlist handling across YouTube, SoundCloud and metadata providers.
- Increased prefetch depth and search-cache lifetime for larger queues.
- Added audio-health reporting, structured playback logs and provider authentication checks.
- Tuned extraction concurrency and search ranking for the higher-capacity deployment profile.

## Upgrade

Back up configuration and data. Review memory limits and `RHAPSOD_MAX_CONCURRENT_YTDLP_JOBS`; the larger profile can use 4 workers. Spotify remains metadata-only. Subsequent releases replace the YouTube resolver paths used here.

## Verification

Play a mixed-provider queue and inspect `!stats` and playback-session logs for underruns, rebuffer events and child-process memory use.
