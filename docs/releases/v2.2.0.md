## Summary

Direct Innertube search and audio resolution, with an optional persistent yt-dlp daemon.

## Changes

- Added Innertube player and search requests with yt-dlp fallback.
- Added guarded redirect resolution and YouTube Music URL support.
- Added a warm Python yt-dlp daemon and per-video URL caching.
- Removed unused youtubei.js and Piped resolver stacks and their settings.

## Upgrade

The daemon is optional. To enable it, install its Python dependencies, run `scripts/yt-dlp-daemon.py`, and set `RHAPSOD_YTDLP_DAEMON_URL=http://127.0.0.1:8765`. Review removed resolver settings against this tag's `.env.example`.

## Verification

Test a text search and a redirected music link. If using the daemon, stop it during an idle test window and confirm a new request falls back to the yt-dlp executable.
