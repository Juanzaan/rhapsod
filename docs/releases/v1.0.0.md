## Summary

First stable Rhapsod release for TeamSpeak 3, with YouTube, SoundCloud and Spotify link support.

## Changes

- Free-text music search with fuzzy matching and provider-aware ranking.
- Spotify track metadata matched to YouTube audio; Spotify does not supply playback.
- FFmpeg process cleanup after skips and recovery from audio-buffer underruns.
- systemd deployment instructions and configurable TeamSpeak client description.

## Upgrade

This is the initial release. Use the source and deployment instructions at `v1.0.0` for historical reproduction. Use the latest release for a new installation.

## Verification

Connect to TeamSpeak, request a YouTube track with `!play`, and test `!skip`. Confirm the previous FFmpeg process exits and the next track starts.
