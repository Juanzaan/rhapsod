## Summary

Final 1.x release, tuned for a 1 vCPU / 1 GB VPS.

## Changes

- Corrected FFmpeg option propagation and removed an option that prevented playback.
- Recalculated talk power after reconnects and avoided blocking playback on chat delivery.
- Preserved search queries so restored tracks can resolve fresh audio URLs.
- Restricted channel movement to administrators and added channel-ID selection.
- Reduced single-core extraction concurrency and improved cancellation and stalled-input handling.

## Upgrade

Back up configuration and data. Configure `RHAPSOD_ADMIN_UIDS` for `!channel-move`; `RHAPSOD_TS3_CHANNEL_ID` can select the startup channel. The 1.x line is historical; current development is on 3.x.

## Verification

Check playback after reconnecting, restore a search-generated queue, and confirm a non-admin cannot move the bot between channels.
