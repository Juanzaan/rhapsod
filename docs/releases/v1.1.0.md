## Summary

Audio scheduling, reconnect handling and queue controls for the first stable release line.

## Changes

- Disabled Opus in-band FEC by default and removed bursts of late audio frames.
- Paused playback during reconnects and bounded graceful shutdown.
- Added persistent volume and loop settings, queue editing, history and ranked search selection.
- Added CI checks and an event-loop watchdog.

## Upgrade

Back up the environment and data directory before changing versions. This historical release used a voice codec identifier corrected in `v1.2.0`; use a later release for deployment.

## Verification

Check that volume and loop settings survive a restart. Test queue editing and confirm audio resumes after a controlled reconnect.
