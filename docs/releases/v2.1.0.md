## Summary

Saved playlists and persistent audio effects.

## Changes

- Added `!playlist` operations with per-user ownership, 20 playlists per user and 200 tracks per playlist.
- Added bassboost, nightcore, vaporwave and 8D effects through FFmpeg.
- Added `!effects` controls and log analysis with `scripts/log-stats.mjs`.
- Improved resolver errors, prefetch observability and contributor tooling.

## Upgrade

Back up the data directory, including the new `playlists.json`. Existing configuration remains usable. Effects persist across restarts and changing an effect restarts the current audio pipeline.

## Verification

Save and reload a playlist, test `!effects bassboost`, then clear it with `!effects reset`. Restart while idle and confirm the saved playlist remains available.
