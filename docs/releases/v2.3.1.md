## Summary

Panel loading, settings validation and version reporting fixes.

## Changes

- Removed the incorrect compressed response length that left the dashboard loading indefinitely.
- Restricted environment writes to supported Rhapsod settings.
- Read the running version from `package.json` under systemd.
- Added panel security headers and a ranged-GET fallback for hosts that reject HEAD.
- Corrected release tag discovery.

## Upgrade

Rebuild and restart while playback is idle. Existing environment settings remain valid. Keep the panel bound to localhost and authenticated.

## Verification

Load the dashboard to completion, confirm the displayed version and save a supported setting. Check that unknown environment keys are rejected by the API.
