## Summary

Owner web panel, guided installation and improved recovery from provider failures.

## Changes

- Added a localhost panel with setup wizard, playback controls, server tree and channel chat.
- Added sanitized error summaries, disconnect tracking and YouTube health checks.
- Added the Linux installer, Docker distribution and optional extraction support services.
- Added bounded audio-URL refresh/retry paths and DNS-pinned outbound checks.
- Introduced prewarm and loudness profiling; handoff scheduling is corrected in `v2.4.0`.

## Upgrade

The panel is disabled by default. Enable `RHAPSOD_PANEL_ENABLED`, set a unique password and retain `RHAPSOD_PANEL_HOST=127.0.0.1`. Access it through an SSH tunnel. Later patches correct panel loading and settings-write issues in this version.

## Verification

Open the setup wizard through the tunnel, verify TeamSpeak connectivity and inspect the YouTube health result. Test playback controls and confirm private messages do not appear in channel chat.
