## Summary

Personal music preferences, adaptive autoplay, live radio and isolated multi-bot hosting.

## Changes

- Added favorites (`!fav`, `!favs`, `!unfav`, `!favplay`), preferred search source (`!fuente`), listening tops and personal stats.
- Added adaptive autoplay using recent listening signals, title-based energy matching, repeat limits and a provider timeout.
- Added radio-directory search with TuneIn fallback and live ICY titles.
- Added `!jump`, queue remaining-time estimates and separate tested queue and playback controllers.
- Added `RHAPSOD_INSTANCE_ID`, duplicate-start detection and recovery from broken log-file streams.
- Fixed settings saves that rejected read-only keys or erased masked secrets; removed external dashboard assets and exposed reconnect status.

## Upgrade

`!skip`, `!jump` and `!remove` require the requester or an administrator for affected tracks. Autoplay tracks remain skippable by everyone. Review `RHAPSOD_ADMIN_UIDS` with channel users.

Back up the environment and data directory. Each additional instance needs its own instance ID and panel port. A duplicate start exits with code 42; use a systemd unit with `RestartPreventExitStatus=42`.

## Verification

Test favorites across a restart, preferred-source searches, radio titles and autoplay after the queue drains. Verify skip permissions with two users and confirm untouched secrets survive a panel settings save.
