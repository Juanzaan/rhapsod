## Resumen

Búsqueda y resolución directa con Innertube, junto con un servicio persistente opcional de yt-dlp.

## Cambios

- Consultas de reproducción y búsqueda de Innertube con alternativa mediante yt-dlp.
- Resolución protegida de redirecciones y enlaces de YouTube Music.
- Servicio Python persistente y caché de URL por video.
- Eliminación de rutas sin uso de youtubei.js y Piped y sus ajustes.

## Actualización

El servicio es opcional. Para activarlo, instalar sus dependencias Python, ejecutar `scripts/yt-dlp-daemon.py` y configurar `RHAPSOD_YTDLP_DAEMON_URL=http://127.0.0.1:8765`. Revisar los ajustes eliminados con `.env.example` de esta etiqueta.

## Verificación

Probar una búsqueda y un enlace musical con redirección. Si se usa el servicio, detenerlo durante una prueba en reposo y confirmar que una solicitud nueva utiliza el ejecutable yt-dlp.
